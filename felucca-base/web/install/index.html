DUELL

MultiMorphing Bitimbral Synthesizer
by OSCILL/R

DUELL beta installer for the M-VAVE FM-1.

DUELL firmware is not yet released. Use the browser emulator while the hardware tests finish.

Open the emulator · Source code

This is a beta. DUELL was developed in a browser emulator and has been run on one real FM-1 by its author; the way back to the official firmware worked about three times, on the author's unit, and has not been tried on others. Installing is at your own risk. If something goes wrong there is no known way to roll back, and the only sure way back is the official firmware (the last card below, "Go back to the official firmware"). Read the recovery notes first. DUELL is not affiliated with M-VAVE.

1Flash checklist

Tick each box. The Install button stays off until all four are ticked.

Afterwards: unplug the FM-1 and plug it in again before you use it.

2Back up (recommended)

BACK UP

Reads the unit and saves a file with your current sounds and settings to this computer. Nothing is written to the FM-1. It needs a firmware that supports backups (Felucca or DUELL). The official M-VAVE firmware cannot be backed up from this page.

Known gap: in this beta the backup does not include MULTIs or the PATTERN slots. Restoring a backup is done in the editor (the editor in the source tree), which has not been adapted to DUELL yet, so restoring is untested.

3The DUELL build

Looking for the build ...

4Connect

Connect the FM-1 by USB and switch it on. Close other programs that use MIDI (a DAW, another browser tab). Chrome will ask to allow MIDI with SysEx: allow it.

5Install

INSTALL DUELL

The page checks what your FM-1 runs now and sets the box below for you. You can always tick or untick it yourself.

Erases your settings (theme, scale, MIDI channels, favourites), the autosave, your patches, your multis and your patterns. The factory sounds, multis and patterns come back. This cannot be undone: back up first (step 2). Left off, your saved data stays and the unit comes back as you left it.

If it stops: replug the cable and press Install again. The FM-1 stays in update mode until the write is finished, and the page resumes it. When it says Done, unplug the FM-1, plug it in again, and check the version under HOME (hold) > ABOUT.

Go back to the official firmware

RETURN TO OFFICIAL FIRMWARE

This writes the official M-VAVE firmware back. DUELL will be removed. Keep the cable connected until DONE.

Download the official FM-1 firmware (FM-1.fwsc, V15) yourself from M-VAVE's download page: m-vave.com/download. This project does not host or redistribute M-VAVE's files. Select the unmodified file here; the page checks it in your browser (it is never uploaded) and only accepts V15.

DUELL music and sounds cannot be opened by the official firmware.
