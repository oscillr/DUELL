1Connect

Connect the FM-1 by USB and press the button. Chrome or Edge asks for MIDI access with SysEx.

2Back up

Saves one file to your downloads: your patches, multis, pattern slots, settings and the current music of both parts. Backing up stops playback on the unit. Nothing is written to the unit.

What is in the file

3Restore

Choose a backup file made by this page (or the installer's backup file of a DUELL unit). The file is checked completely before anything is sent.

What is in this file

Replace on the unit:

Everything of a chosen kind on the unit is replaced by what the file holds, including slots that are empty in the file. The unit stops playback by itself before it writes and checks every object (size, checksum, content) before it commits it; a power cut leaves each object as it was or as it is in the file.

Settings include the button map (calibration) of the unit that made the file. Restore settings from another unit only if you mean to.

Before it writes, this page saves a safety backup of the unit to your downloads. If a restore stops half way, the safety file and the file you chose both stay valid: restore again.

Firmware before DUELL 0.2.14 cannot back up or restore multis and pattern slots; update with the installer. This page never updates the firmware. DUELL is released under the GPL-3.0 with no warranty; see NOTICE.
