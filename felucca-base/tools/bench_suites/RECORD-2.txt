# RECORD-2: the repeat suite for the recorder with a start mark (release_drafts/BENCH_RECORD2.md). About 22 minutes. Run it with --record (python3 with numpy), two cores.
# Each heavy scene is run three times on one core (core 1 given no jobs: the reference) and three times on two cores, back to back, to see whether clicks near the start repeat;
# M07 once each. `repeat N` runs a test N times in a row (each repeat does its own `bench reset`; no restart); the summary has an aggregate line per test, and a test passes only if
# every repeat is clean. `--repeat N` on the command line overrides these lines. The reference runs first for each scene; repeat k of the two-core test is compared with repeat k
# of the reference (same click times within 60 ms = the scene's own, WARN; a click only on two cores = FAIL).
# The scenes, the cycles and the BENCHT4 settings are those of RECORD-1.
suite RECORD-2

cycle M07-CYCLE period 20
at 0.0  chord C3 E3 G3 B3 vel 90
at 4.0  release
at 4.0  chord A2 C3 E3 G3 vel 90
at 8.0  release
at 8.0  chord F2 A2 C3 E3 vel 90
at 12.0 release
at 12.0 chord G2 B2 D3 F3 vel 90
at 14.0 morph 0 127 over 2
at 16.0 release
at 16.0 chord C3 E3 G3 B3 vel 90
at 16.0 aftertouch 0 127 over 2
at 18.0 morph 127 0 over 1
at 19.0 aftertouch 127 0 over 0.9
at 19.9 release
end

cycle STRESS-HOLD period 600
at 0.0  chord C3 E3 G3 B3 D4 F4 A4 C5 vel 64 ch 1
at 0.0  chord G3 B3 D4 F#4 A4 C5 E5 G5 vel 64 ch 2
end

# ---- STRESS (the heavy scene), 3 repeats each

test STRESS-1CORE  heavy 8 + 8 DUEL scene, 140 s, x3; core 1 given no jobs (one-core reference)
onecore-of STRESS-DEF
repeat 3
scene "HVY DUEL 8+8"
tune slack 400000
soak 140 repeat STRESS-HOLD
check 30
tail 3
expect report

test STRESS-DEF  heavy 8 + 8 DUEL scene, 140 s, x3; the BENCHT4 defaults (two cores)
repeat 3
scene "HVY DUEL 8+8"
ref 58.8 78.3
soak 140 repeat STRESS-HOLD

expect report
