# TWOCORE-3: the BENCHT4 suite (release_drafts/BENCH_TWOCORE4.md). About 8 minutes: the three scenes once each with the BENCHT4 defaults, and the heavy scene once more with BENCHT3's
# run and window pause rules switched on, for contrast.
# BENCHT4's rule ("pause only for real faults"): the jobs pause for a fault (a wrong answer, a refused job, no answer, a crash), for a job that did not finish by its wait limit
# (a silent block), and for a run of 4 late blocks (core 1 not picking up jobs). A very late block whose job finished by the wait limit NEVER pauses, however many in a row or in a
# window; it is counted ("very late without a pause"). The deadline floor is off by default. The defaults are what the first three tests run; the 4th puts BENCHT3's two rules back
# (`tune vrun 4`, `tune vwin 8 2000`: 4 very late in a row, or 8 within 2 s, pause for 10 s).
# Verdicts (the runner): very late blocks without a pause = WARN with the count; any pause = FAIL, except in the contrast test (its own `diag`: a pause is WARN there, counted);
# a silent block, a refused job, a missed half, a core 1 that stops = FAIL.
# `ref A P`: the CPU average and peak BENCHT3 gave with the pauses off (its best case); the summary prints them beside this run's. One core played the heavy scene at 66.3 %.
