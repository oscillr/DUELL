Thank you. Each line names the source, the link, the licence and what DUELL uses. The same list, with the exact files, is in [NOTICE.md](NOTICE.md) and [felucca-base/LICENSING.md](felucca-base/LICENSING.md). DUELL itself is GPL-3.0-only.

**The base**
- **Felucca** by Leo Kuroshita (@kurogedelic), Hügelton Instruments, <https://github.com/hugelton/Felucca>, GPL-3.0. DUELL is a modified version of it.

**Ideas and code that came into DUELL**
- **Velo** (fm1-velocity) by **Charles Vestal**, <https://github.com/charlesvestal/fm1-velocity>, GPL-3.0-only. The method of key velocity and aftertouch (KEY SENSE). The code is written again for DUELL; none is copied.
- **JIANT** by juanjiant-bit, <https://github.com/juanjiant-bit/JIANT>, GPL-3.0. The SHIM and RESO reverbs.
- **CHOMPI Club**, <https://github.com/CHOMPI-Club/CHOMPI>, MIT. The idea of the PLATE reverb (Emilie Gillet's plate reverb, rewritten as integer code) and of the RAND and OCT+ delay modes; no code copied. The name and logo of CHOMPI are not used.
- **Emilie Gillet** (Mutable Instruments), <https://github.com/pichenettes/eurorack>, MIT. Rings and Clouds reverb design, and Rings' sympathetic strings (PHYS engine).
- **DaisySP** by Electrosmith, <https://github.com/electro-smith/DaisySP>, MIT. The PHYS engine's modal and string models.
- **msfa** from **Dexed** by Google Inc. and Pascal Gauthier, <https://github.com/asb2m10/dexed>, Apache-2.0. The FM6 engine's synthesis.
- **CrispyZebra** by Leo Kuroshita (Hügelton Instruments), <https://github.com/hugelton/CrispyZebra>, GPL-3.0. The PHASE engine's oscillator.
- **klattsch** by Tony Gies, <https://github.com/tgies/klattsch>, MIT. A design reference for the VOICE engine; no code copied.
- **aquanodemusic** (Aquanode Soundscapes), <https://github.com/aquanodemusic/aquanode-soundscapes>, CC0 1.0. One FM bass voice (the sound FM BASS 2).
- **J. W. Cooley and J. W. Tukey** (the fast Fourier transform, 1965) and the wavetable file convention of **Xfer Serum**, also used by Vital and Surge: ideas for the WAVE user tables; no code of anyone else.

**Fonts, icons and the packages**
- **Inter Tight** by The Inter Project Authors, SIL OFL 1.1. The text on the screen.
- **Fukiai** icon font by Hügelton Instruments, <https://github.com/hugelton/Fukiai>, MIT.
- **JieLi AC79 SDK** by JieLi Technology, Apache-2.0: three unmodified files inside every firmware package.
