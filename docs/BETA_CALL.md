# Beta call-out: emulator beta

**DUELL**
MultiMorphing
Bitimbral Synthesizer
by OSCILL/R

DUELL is free, open-source firmware for the M-VAVE FM-1, built on Felucca: two synths in one box, with SPLIT, STEREO and LAYER modes and a morph fader between two versions of every sound.
Public beta: the browser emulator is open now, no FM-1 needed: https://oscillr.github.io/DUELL/emu/
The firmware has run on one real FM-1 (the author's). It is not released yet and follows after more hardware testing, so please do not flash anything.
Please play with it and tell me what breaks (bug report form: https://github.com/oscillr/DUELL/issues/new/choose; what to test: https://github.com/oscillr/DUELL/blob/main/docs/TESTING.md).
Source and docs: https://github.com/oscillr/DUELL. Free software (GPL-3.0), no warranty, not affiliated with M-VAVE.
