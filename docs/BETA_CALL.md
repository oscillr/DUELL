# Beta call-out: DUELL 0.2.13 beta

**DUELL**
MultiMorphing
Bitimbral Synthesizer
by OSCILL/R

DUELL is free, open-source firmware for the M-VAVE FM-1, built on Felucca: two synths in one box, with DUEL, STEREO and LAYER modes and a morph fader between two versions of every sound.
The first firmware beta (0.2.4) is out, with a web installer, and the browser emulator needs no FM-1: https://oscillr.github.io/DUELL/emu/
Careful: it has been tried on only one FM-1 (the author's). The way back to the official firmware worked about three times on that unit. Install at your own risk; the install steps and recovery notes are in the docs: https://github.com/oscillr/DUELL/blob/main/docs/INSTALL.md
Please play with it and tell me what breaks (bug report form: https://github.com/oscillr/DUELL/issues/new/choose; what to test: https://github.com/oscillr/DUELL/blob/main/docs/TESTING.md).
Source and docs: https://github.com/oscillr/DUELL. Free software (GPL-3.0), no warranty, not affiliated with M-VAVE.
