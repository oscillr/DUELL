# TWOCORE-2: the BENCHT3 suite (release_drafts/BENCH_TWOCORE3.md). About 10 minutes: three scenes, each under five settings of the runner, so one command shows what the two changes of BENCHT3 do.
# The two changes: (1) a very late block whose job still finished inside its half no longer pauses core 1 by itself (it pauses for a real fault, for 4 very late blocks in a row, or 8 within 2 s);
#                  (2) the deadline has a floor from core 1's own measured run time (`bench floor 1`).
# The five settings (each test sets them itself after its `bench reset`; reset puts them back):
#   NEW-F1  new pause rule, floor on     = the BENCHT3 defaults
#   NEW-F0  new pause rule, floor off    (what the pause rule alone does)
#   OLD-F1  old pause rule (`vrun 1`: one very late block pauses 10 s), floor on
#   OLD-F0  old pause rule, floor off    = BENCHT2's S1 (compare with its numbers)
#   POFF    pause off (no pause for late or very late blocks), floor off = BENCHT2's POFF; a real fault still pauses
# On a BENCHT4 or later build the defaults changed (run and window rules off, floor off): "NEW" then means BENCHT4's rule (the tests that name `floor` set it themselves). TWOCORE-3 is the BENCHT4 suite.
# Scenes: M07-style CHORDS (17 s, the OWNER-1 test), M07 cycle (60 s: chord changes, MORPH, aftertouch), heavy 8 + 8 DUEL STRESS (40 s).
# `ref A P`: the CPU average and peak the same scene gave in BENCHT2 (OLD-F0 numbers on every test of the scene except POFF, which carries BENCHT2's POFF numbers); the summary prints them beside this run's.
# `diag`: very late blocks and pauses are WARN here (the point of the run is to count them); silent blocks, refused jobs, missed halves and a core 1 that stops stay FAIL.
suite TWOCORE-2
diag

cycle M07-CYCLE period 20
at 0.0  chord C3 E3 G3 B3 vel 90

at 16.0 release
at 16.0 chord C3 E3 G3 B3 vel 90
at 16.0 aftertouch 0 127 over 2
at 18.0 morph 127 0 over 1
at 19.0 aftertouch 127 0 over 0.9
at 19.9 release
end

at 0.0  chord C3 E3 G3 B3 D4 F4 A4 C5 vel 64 ch 1
at 0.0  chord G3 B3 D4 F#4 A4 C5 E5 G5 vel 64 ch 2
